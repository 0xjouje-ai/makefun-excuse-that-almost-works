The excuse a gamer texts the boss to skip work on GTA 6 launch week — one line, 16 words, boring enough to almost believe: the council is resurfacing the street tomorrow and they've towed the car. No build step, no network, no dependencies: `main.ts` writes the line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt`.
